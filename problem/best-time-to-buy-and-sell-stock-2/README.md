# best-time-to-buy-and-sell-stock-2

## 問題要約

与えられた整数配列 `prices`
は各日の株価を表します。各日に株を買ったり売ったりできますが、同時に保有できる株は最大で1株です。買ったその日にすぐ売ることも許されます。取引回数に制限はなく、利益の合計を最大化してください。返すべき値は達成可能な最大利益です。

例：

- prices = [7,1,5,3,6,4] のとき最大利益は 7（1→5 と 3→6
  の2回の取引で得られる）。
- prices = [1,2,3,4,5] のとき最大利益は 4（1 を買って最後に売る）。
- prices = [7,6,4,3,1] のとき最大利益は 0（利益を得られないので取引しない）。

## 制約

- 配列長: \(1 \le \text{prices.length} \le 3 \times 10^4\)
- 各価格: \(0 \le \text{prices}[i] \le 10^4\)

（時間・空間的制約として配列長が最大3万なので、O(n) または O(n log n)
程度のアルゴリズムが望ましい）

## 考え方

この問題は「いつでも売買できる（複数回取引可）」という条件のもと、単に上昇している区間の差分を全て足し合わせればよいという直観的な解が成り立ちます。理由は次の通りです。

- もし日 i から日 j (i < j)
  にかけて価格が単調増加している区間があるなら、その区間全体の買い（最初の日）→売り（最後の日）で得られる利益は
  prices[j] - prices[i] です。
- ただし同じ区間で毎日の上がり下がりを分割して（その都度買って売って）得られる利益の合計は各日の増分の和、すなわち
  (prices[i+1]-prices[i]) + (prices[i+2]-prices[i+1]) + ... =
  prices[j]-prices[i] と等しいです。
- よって各隣接日の価格差の正の部分だけを足し合わせれば、最適な利益が得られます。

アルゴリズム（1パス・貪欲）：

- totalProfit を 0 に初期化。
- i を先頭から走査し、もし prices[i] < prices[i+1] なら totalProfit +=
  prices[i+1] - prices[i]。
- 最後に totalProfit を返す。

時間計算量: \(O(n)\)、空間計算量: \(O(1)\)。
