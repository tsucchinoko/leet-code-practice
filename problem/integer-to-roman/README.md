## 問題の性質

この問題は与えられた1〜3999の整数を、古典的なローマ数字表記に変換する問題です。決められた記号と減法表記（subtractive
notation）を使って、各桁（千、百、十、一）ごとに変換した結果を結合します。決定性が高く、文字列操作と定数テーブルの参照で解ける整列的な問題です。

## 問題要約

与えられた整数 `num` (1 ≤ num ≤ 3999)
をローマ数字に変換して文字列で返す。ローマ数字のルールは次の通り。

- 記号と値: I=1, V=5, X=10, L=50, C=100, D=500, M=1000
- 桁ごと（千・百・十・一）に最大位から変換し、結果を連結する。
- 4 と 9 の始まり（4, 9, 40, 90, 400, 900）は減法表記（IV, IX, XL, XC, CD,
  CM）を使う。
- 1,10,100,1000 を表す記号（I, X, C,
  M）は最大3回まで繰り返せる。5,50,500（V,L,D）は繰り返さない。

例:

- 3749 → "MMMDCCXLIX"
- 58 → "LVIII"
- 1994 → "MCMXCIV"

## 制約

- 入力は整数で、1 ≤ num ≤ 3999。
- 出力は標準的なローマ数字の表記に従うこと（上記で許可された減法表記のみを使用）。
- パフォーマンス面では単一の整数変換なので、時間・メモリは問題にならない（O(1)
  に近い）。

## 考え方

1. 変換を桁ごと（千、百、十、一）に分けて考える：各桁の値は 0〜9
   の範囲に正規化できる。
2. 各桁に対応するローマ記号の組（1の位のための (I, V, X)、10の位のための (X, L,
   C)、100の位のための (C, D, M)、1000の位は単純に M を繰り返す）を用意する。
3. 桁値 d に対してルール適用：
   - d == 0 → ""
   - 1 ≤ d ≤ 3 → base を d 回繰り返す（例: 3 → "III"）
   - d == 4 → base + five（例: 4 → "IV"）
   - d == 5 → five（例: 5 → "V"）
   - 6 ≤ d ≤ 8 → five + base*(d-5)（例: 7 → "VII"）
   - d == 9 → base + next（例: 9 → "IX"）
4. 1000の位は d = num / 1000 を M を d 回繰り返して処理する（d ≤ 3
   になるよう制約で保証される）。
5. 桁ごとの結果を高位から順に連結して完成。

性質としてはルールが固定で決まりきっているため、実装は単純な条件分岐とテーブル参照で書ける。エラーケースは存在せず入力範囲に収まれば必ず一意の出力が得られる。

## キーワード

- ローマ数字
- 減法表記（subtractive notation）
- 桁ごと変換
- 定数テーブル
- 文字列連結
