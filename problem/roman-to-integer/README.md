## 問題の性質

文字列処理、置換・走査による数値変換。入力はローマ数字で与えられ、左から右へ走査して対応する整数値を計算する。線形時間で解け、状態をほとんど持たないため実装容易。

## 問題要約

与えられた有効なローマ数字文字列 s（長さ 1〜15、値は
1〜3999）を整数に変換する問題。ローマ数字は基本的に大きい順に並ぶが、特定の組み合わせ（IV,
IX, XL, XC, CD, CM）のときは減算表記が用いられる。これらを考慮して合計を求める。

## 制約

- 1 <= s.length <= 15
- s は 'I','V','X','L','C','D','M' のみを含む
- s は有効なローマ数字であり、その表現は値が 1〜3999 の範囲にある
- 時間複雑度：O(n) が望ましい（n = s.length）
- 追加メモ：メモリは定数オーダーで十分

## 考え方

1. ローマ字1文字ごとに対応する値を持つマップを用意する（I=1, V=5, X=10, L=50,
   C=100, D=500, M=1000）。
2. 左から右へ1文字ずつ走査する。現在の文字の値を cur、次の文字の値を next
   とする。
3. もし cur < next であれば、これは減算表記（例: IV, IX, ...）なので総和に
   (next - cur)
   を加え、次の文字をスキップして進める（インデックスを2つ進める）。
4. それ以外（cur >= next または次が存在しない）の場合は総和に cur
   を加えてインデックスを1つ進める。
5. 走査終了後の総和が答え。

別の等価な実装:
各文字を足していき、前の文字の値が現在の文字の値より小さければ前の値を二回引く手法（累積済み前値を調整）もある。どちらも
O(n)。

問題の性質（簡潔）:
グリーディ（局所比較）かつ線形走査。特別ケースは6種類の減算ペアのみ。

## キーワード

- ローマ数字
- 走査（線形）
- 減算表記（subtractive notation）
- マップ（辞書）
- O(n)
