# Insert-Delete-GetRandomO1

## 問題の性質

データ構造設計問題。挿入・削除・ランダム取得を平均 O(1)
で行う必要がある。ハッシュ表と配列（スライス）を組み合わせた実装が標準的。

## 問題要約

RandomizedSet クラスを実装する。

- RandomizedSet() — オブジェクト初期化
- insert(val int) bool — val を集合に挿入。存在しなければ挿入して
  true、すでに存在すれば false を返す。
- remove(val int) bool — val を集合から削除。存在すれば削除して
  true、存在しなければ false を返す。
- getRandom() int —
  現在の集合から等確率で要素を1つ返す（呼び出し時に少なくとも1要素存在することが保証される）。

各操作は平均 O(1) 時間で動作すること。

## 制約

- 値の範囲: -2^31 <= val <= 2^31 - 1
- insert/remove/getRandom の合計呼び出し回数は最大 2 * 10^5
- getRandom が呼ばれる際は少なくとも1要素が存在することが保証される

メモリはスライスとマップを使う設計で十分。

## 考え方

目的は「挿入・削除・ランダム取得を平均
O(1)」で実現すること。ハッシュマップだけではランダム取得が O(n)
になり、配列だけでは削除が O(n) になり得る。よって両者を組み合わせる。

基本アイデア:

- 値を格納するスライス values []int を持つ。getRandom
  はこのスライスからランダムインデックスを取れば O(1)。
- 値からスライス内インデックスを得る map idxMap map[int]int
  を持つ。これにより、値が存在するか、またその位置を O(1) に判定できる。
- remove の O(1) 実現法:
  削除したい要素をスライス末尾の要素と入れ替え、末尾を切る（pop）。入れ替えた要素のインデックスを
  map で更新する。これによりスライスの中間要素削除が O(1) になる。
- insert は map で存在確認後、末尾に追加し map を更新。
- getRandom は rand.Intn(len(values)) でランダムにインデックスを取り要素を返す。

注意点:

- rand
  のシードは初期化時に設定する（テストの再現性が必要なら固定シードを使うが通常は時間でシード）。
- map とスライスは同時に一貫性を保つこと。
- 値の範囲が int32 相当でも Go の int で扱って通常問題ない（環境依存だがここでは
  OK）。

## キーワード

- ハッシュマップ（map）
- 配列（スライス）
- スワップ削除（swap-and-pop）
- 等確率ランダム選択
- 平均 O(1)
