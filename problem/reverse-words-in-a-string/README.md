# reverse-words-in-a-string

## 問題の性質

文字列処理、文字列分割と再結合。主にパース（単語抽出）と並べ替え（逆順）を行う簡潔な文字列操作問題。余分な空白処理（前後の空白・複数空白を単一空白へ）も含む。配列（スライス）操作や双方向ポインタでのインプレース反転が重要。

## 問題要約

入力文字列 s
に含まれる単語（空白で区切られる非空白文字の列）を取り出し、単語の順序を逆にして単一の空白で結合した文字列を返す。返り値は前後に空白を含まず、単語間はちょうど1つのスペースとする。

例:

- 入力: "the sky is blue" → 出力: "blue is sky the"
- 入力: " hello world " → 出力: "world hello"
- 入力: "a good example" → 出力: "example good a"

## 制約

- 1 <= s.length <= 10^4
- s は英字（大小）、数字、およびスペース ' ' を含む
- 少なくとも1つの単語が存在する
- 言語によっては文字列がミュータブル（変更可能）かどうかが異なり、フォローアップで「O(1)
  追加メモリでインプレース解法」を問う

## 考え方

1. 単純で安全な方法（追加メモリを使用）:
   - 文字列を走査して単語を抽出（空白区切り、連続空白を無視）。
   - 単語をスライス（配列）に格納し、最後に逆順で結合して1つの文字列にする（単語間は1つのスペース）。
   - 実装は簡潔で直感的。時間計算量 O(n)、追加空間
     O(k)（単語数と長さの合計、結合結果を除くと一時配列分）。

2. インプレース（O(1) 追加メモリ）を目指す方法（文字列がミュータブルな場合、例:
   byte 配列）:
   - 文字列（またはバイト配列）全体を反転する。
   - 各単語の順序が逆になるため、各単語の文字列自体を再度反転して単語内部を正しい順に戻す。
   - 同時に余分な空白（前後・連続）を詰めて置き換えることで結果を1つの配列に収める。
   - 手順の要点:
     1. 全体反転
     2. 単語ごとに反転（単語検出は空白で区切る）
     3. 左詰めで空白を1つにまとめる（書き込みポインタを使う）
   - 時間計算量 O(n)、追加空間 O(1)。

問題の特徴は単語抽出と空白の正規化が主で、逆順にするだけなのでアルゴリズムは比較的単純。入力サイズが小さい（≤10^4）ためどちらの方法でも実用的。

## キーワード

- 文字列分割
- trim（前後空白除去）
- split（空白で分割）
- join（単語結合）
- in-place reverse（インプレース反転）
- two pointers（双方向ポインタ）
- O(n) time, O(1) space（フォローアップ目標）
