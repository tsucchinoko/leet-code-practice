# Length-of-Last-Word

## 問題の性質

文字列処理（文字列走査）、線形時間アルゴリズムで解ける簡単な実装問題。追加のメモリはほとんど不要（O(1)）で、入力長に対して一回の走査で解ける。

## 問題要約

空白と単語からなる文字列 s
が与えられる。最後の単語（末尾の空白を無視したときに最後に現れる非空白連続部分）の長さを返す。単語は空白以外の最大連続部分列と定義される。

例:

- "Hello World" → 最後の単語 "World" の長さ 5
- " fly me to the moon " → "moon" の長さ 4
- "luffy is still joyboy" → "joyboy" の長さ 6

## 制約

- 1 <= s.length <= 10^4
- s は英字と空白 `` のみで構成される
- 少なくとも1つの単語が存在する（つまり全て空白のケースはない）

時間計算量目標: O(n)（n = s.length） 追加空間: O(1)

## 考え方

1. 末尾に余分な空白がある可能性があるので、まず末尾の空白をスキップする（後ろから走査）。
2. 続いて空白でない文字を数える（これが最後の単語の長さ）。空白または文字列の先頭に達したら終了。
3. 最後に数えた長さを返す。

この方針は一度だけ文字列を後ろから走査するため O(n)
で、追加メモリは定数で済む。前から走査して区切り毎に長さを更新する方法（各単語長を追う）でも解けるが、後ろから開始する方が末尾の余分な空白処理がシンプル。

境界条件:

- 末尾に複数空白がある場合 → まずスキップされる
- 単語が先頭にある場合 → 正常にカウントされる
- 最小長の文字列（長さ1で文字のみ） → 正常に1を返す
