# remove-duplicate-from-sorted-array-2

## 問題要約

整数配列 nums
が非減少順（ソート済み）で与えられる。配列をインプレースで変更して、各異なる要素が最大で2回までしか残らないように重複を削除せよ。配列の先頭
k 個に結果を格納し、関数は k を返すこと。追加の配列は使えず、O(1)
の追加メモリで行うこと。要素の相対順序は保たれる必要がある。

例:

- 入力: [1,1,1,2,2,3] -> 出力 k=5, nums の先頭5要素: [1,1,2,2,3,...]
- 入力: [0,0,1,1,1,1,2,3,3] -> 出力 k=7, nums の先頭7要素: [0,0,1,1,2,3,3,...]

## 制約

- 1 <= nums.length <= 3 * 10^4
- -10^4 <= nums[i] <= 10^4
- nums は非減少順（ソート済み）
- 追加配列を使わず、O(1) の追加メモリでインプレースに変更すること

## 考え方

ポイントは「ソート済み」という性質を利用して、走査しながら書き込み位置を管理すること。各値は連続して現れるため、同じ値の出現回数を数えながら、2回目までを受け入れ、それ以上はスキップすればよい。

効率的で単純な二つのポインタ法（読み取りポインタ i、書き込みポインタ
j）を使う方法：

- j は次に書き込む位置（結果配列の長さを示す）を指す。
- 配列を先頭から順に読み取り i を進める。
- i 番目の要素 nums[i] を書き込むかどうかは、j
  の位置（すでに書き込んだ最後の要素）を参照して決める。
- 実装の簡潔な方針: 最初の2個の要素（j <
  2）はそのまま受け入れる（常に書き込む）。
- それ以降は、nums[i] が現在の結果配列の最後から2つ目の要素 nums[j-2]
  と異なれば受け入れる（つまり、その値がまだ2回未満であることを保証する）。
- 受け入れる場合は nums[j] = nums[i]; j++。
- 最後に j が k（残す要素数）となるのでこれを返す。

この方針は一次走査で O(n) 時間、追加メモリ O(1) を満たす。

注意点:

- 配列長が 1 や 2 の場合はそのまま全要素を残す（j 初期処理が保証）。
- nums の要素範囲や負の値は判定に影響しない。
