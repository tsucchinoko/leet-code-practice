# number-of-recent-calls

## 問題の性質

データ構造（キュー／スライディングウィンドウ）を用いる単純な実装問題。時間順に到着するリクエストのうち、直近3000ミリ秒以内に属するものをカウントする操作を反復的に行う。オンラインでの追加（ping）と範囲内要素の削除（古いリクエストを除去）を効率よく行えばよい。

## 問題要約

RecentCounter クラスを実装する。

- RecentCounter() は初期化を行う。
- int ping(int t) は時刻 t（ミリ秒）で新たなリクエストを追加し、区間 [t - 3000,
  t] に含まれるリクエスト数を返す。 呼び出しは常に増加する t を与える（strictly
  increasing）。

例:

- ping(1) -> 1
- ping(100) -> 2
- ping(3001) -> 3
- ping(3002) -> 3

## 制約

- 1 <= t <= 10^

9

- 各 ping 呼び出しの t は前回より大きい（単調増加）
- ping の呼び出し回数は最大 10^4
- メモリ・時間は通常の制約内（線形・対数時間が許容される）

## 考え方

1. 要求は時刻が単調増加で与えられるため、過去のリクエストを時系列で保持するデータ構造（先入れ先出し／キュー）が適切。
2. ping(t) で新しい時刻 t をキューの末尾に追加する。
3. キューの先頭（最も古いリクエスト）が t - 3000
   より小さい（つまり範囲外）であれば、先頭から取り除く。これを範囲外の要素がなくなるまで繰り返す。
4. 最終的にキューに残った要素数が区間 [t - 3000, t] にあるリクエスト数なので

それを返す。 5.
各リクエストはキューへの追加と一度だけ削除が起きるため、全体での時間計算量は
amortized O(1) 、各 ping を O(1)
平均で処理できる。メモリは保持するリクエスト数に比例（最悪 O(n)）。

問題の性質（簡潔）:

- オンライン処理、単調入力、キューを用いるスライディングウィンドウ。

## キーワード

- キュー (FIFO)
- スライディングウィンドウ
- 単調増加入力
- amortized O(1)
